## Before Opening a Pull Request

Your ideas and suggestions are welcome! Before working on a new feature, we would first like to know whether it fits within the scope of Just Focus. We ask that contributors [create a feature request](https://github.com/LEB-EPFL/just-focus/discussions/new?category=ideas) or a [bug report](https://github.com/LEB-EPFL/just-focus/issues/new) so that we can discuss your proposal before deciding to move forward with an implementation.

We (the maintainers) reserve the right to refuse any proposed change, so please discuss with us first before coding anything.

## Can I use AI?

Yes! You are welcome to use AI tools such as Claude Code to implement a feature or bug fix. All changes, whether written by human or AI, must still be reviewed by a human in a pull request, and we expect that you are able to explain any part of the pull request when asked. Full responsibility for the proposed change lies with the author of the pull request.

If you are unsure about an implementation detail, please [start a discussion](https://github.com/LEB-EPFL/just-focus/discussions/new?category=q-a) and ask.
